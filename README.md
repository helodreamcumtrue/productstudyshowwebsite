## 🚀 Featured Case Studies & Product Teardowns

### 1. 🏦 New Better PNB — UI/UX Mobile Banking Redesign
- **Overview:** Modernizing Punjab National Bank's mobile experience for modern digital India.
- **Key Solutions:** Simplified fund transfers, unified dashboard, clear transaction timeline, and accessible typography.
- **Assets:** High-resolution interactive previews + [Original PDF Presentation](./PNB%20Redesign%20by%20Lakshay.pdf).

### 2. 💬 Improving Discord for New Users — FTUX & Product Teardown
- **Overview:** Frictionless first-time user experience (FTUX) solving server discovery anxiety and interface clutter.
- **Framework:** RICE prioritization model (Interactive Server Tour, Smart Micro-Guides, Simplified Voice Channels).
- **Assets:** High-resolution interactive previews + [Original PDF Presentation](./Discord%20product%20teardown%20by%20Lakshay.pdf).

### 3. 🍕 Domino's New Packaging — Strategic Redesign & Teardown
- **Overview:** Sustainable, thermally efficient pizza packaging redesign eliminating condensation and heat dissipation during 30-minute delivery guarantees.
- **Highlights:** Hexagonal dual-flute corrugated cardboard, steam-vent labyrinth, and optimized stack stability.
- **Assets:** High-resolution packaging schematics + [Original PDF Presentation](./Domino_s%20product%20teardown%20by%20Lakshay.pdf).

### 4. 📱 Improving the Reels Experience on Instagram — Product Teardown
- **Overview:** Deep-dive into creator fatigue and algorithmic discovery on Instagram Reels (200B+ daily plays).
- **Key Innovations:** Built-in multi-track In-Camera Studio & Collaborative Reels co-authoring flows.
- **Assets:** User journey synthesis + [Original PDF Presentation](./Insta%20product%20teardown%20by%20Lakshay.pdf).

### 5. ⚡ ArtiApply — AI Cold Outreach Engine
- **Overview:** High-deliverability SaaS pipeline featuring BullMQ rate-limiting queues, Gmail API automation, and Supabase Realtime campaign telemetry.

### 6. 🧺 Laundify — Campus Service App
- **Overview:** On-demand IoT laundry companion for university residence halls, eliminating laundry room queues with live telemetry, machine reservations, and instant payments.

## 🎨 Features & Design System

- **Dynamic Accent Theme Switcher:** 6 curated color themes (Signature Blue, Electric Purple, Emerald Green, Hot Coral, Tangerine Orange, Cyber Cyan).
- **Dual Architecture:** Framer SSR with React hydration layer synchronized with static HTML/JS fallback.
- **Interactive Modals:** Detailed modal sheets with project metadata, challenges, user research, and approach.
- **PDF Deliverables:** Seamless delivery of full PDF case study presentations directly in the browser.

## 🛠️ Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/helodreamcumtrue/productstudyshowwebsite.git
   cd productstudyshowwebsite
   ```

2. **Start the local server:**
   ```bash
   node server.js
   ```

3. **Open in browser:**
   ```
   http://localhost:3000
   ```
